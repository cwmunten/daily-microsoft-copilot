# Daily Microsoft Copilot

Nederlandstalige webapp voor dagelijkse Microsoft Copilot-updates in Advantive-huisstijl.

## Functies
- Vandaag-overzicht met uitklapbare updates
- Archief per datum
- Zoekfunctie over titel, samenvatting en inhoud
- Responsive desktop/mobiel
- Vercel Cron endpoint voor dagelijkse verversing

## Ontwikkeling
```bash
npm install
npm run dev
```

De eerste versie gebruikt voorbeelddata. De cron-route is voorbereid om later de automatische nieuwsimport aan te sluiten op officiële Microsoft-bronnen en persistente opslag.
